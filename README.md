## About

This repository is my running log of DSA problem-solving — a mix of LeetCode and GeeksforGeeks problems, each solved in a single, self-contained C++ file. The goal is consistency: work through core patterns (arrays, trees, heaps, greedy, backtracking, and more) one problem a day until they stop being unfamiliar.

## Repository Structure

Solutions live flat in the repo root, one `.cpp` file per problem:

```
<LeetCode Problem Number>. <Problem Title>.cpp     # LeetCode solutions
GFG_<Problem Title>.cpp                            # GeeksforGeeks solutions
```

Each file is self-contained — includes, a solution class/function, and (where useful) a small driver for local testing.

## Running a Solution

Any file compiles and runs standalone with a standard C++17 compiler:

```bash
g++ -std=c++17 -O2 -o solution "1. Two Sum.cpp"
./solution
```
